# Zuu Music – Native PWA & Web Player 🎧✨

A high-fidelity modern music streaming web application built with **React 19**, **Tailwind CSS v4**, **Vite**, **Lucide Icons**, and Web Audio API.

Features an **iOS 18 Liquid Glass Transparent UI**, 100% background playback with screen locked/minimized, studio 5-band DSP equalizer, direct MP3 & APK download, and synced karaoke lyrics.

## 🌟 Key Features

### 💎 iOS 18 Liquid Glass & Native Mobile Feel
- **Pure Native App Experience**: Over-scroll bounce disabled, safe-area cover insets, zero web browser chrome feel.
- **Haptic Feedback**: Light, medium, and heavy vibration pulses on interactive controls.
- **Dynamic Island Toast**: Floating liquid status notifications.
- **Dynamic Blurred Ambient Backdrop**: Real-time album color reflections.

### 📱 Background Playback & MediaSession
- **Screen Lock Continuous Play**: Continues audio playback seamlessly when phone screen is locked or app is minimized.
- **Full MediaSession API**: Lockscreen controls for play, pause, seek, previous, and next track.

### 📥 Direct App & Offline Downloads
- **Direct Android APK Download**: 1-click download of `Zuu-Music.apk` directly to phone.
- **Direct Standalone Web Launcher**: 1-click download of `Zuu-Music-App.html`.
- **1-Click Native PWA Install**: Instant installation prompt for Android and iOS.
- **Offline MP3 Storage**: Direct track caching for internet-free playback.

### 🎛️ Studio 5-Band Equalizer & Visualizer
- **5-Band DSP Audio Equalizer**: 60Hz (Sub-Bass), 250Hz (Bass), 1kHz (Mid), 4kHz (High-Mid), 12kHz (Treble).
- **Curated Presets**: Flat, Bass Boost, Vocals, Acoustic, Electronic, Rock & Live.
- **Live Soundwave Visualizer**: Real-time dancing audio frequency canvas.

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/jubayer4455/zuumusic.git
cd zuumusic

# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
